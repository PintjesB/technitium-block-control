Technitium Adblock Control – Settings

This extension connects your browser to the Technitium DNS Server API to control DNS ad blocking per client and conveniently allow blocked domains temporarily or permanently.

What does the extension do?

  • Ad blocking on/off permanently or for a timed interval.
  • Show blocked domains from Technitium Query Logs, filtered to your client IP.
  • Compare with the current page to show which blocked domains belong to it.
  • Allowlist with one click using Allow or Temp Allow directly from the popup.

Requirement: Query Logs must be enabled in Technitium using a queryable logging app such as Query Logs (Sqlite).
